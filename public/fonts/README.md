# Invitation fonts

The website and Remotion composition bundle local font files from the `@fontsource` packages: Playfair Display for prominent couple names and invitation titles, Cormorant Garamond for section headings and editorial copy, and Lato for supporting text. This works offline and avoids a third-party font request. To change fonts, replace the imports in `src/main.jsx` and `video/EngagementVideo.jsx` with licensed `@fontsource` packages, or add licensed WOFF2 files here and point the corresponding CSS `@font-face` rules to them.
