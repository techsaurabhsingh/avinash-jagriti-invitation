# Couple photo gallery

Replace the placeholders by adding your real photographs with these names:

- `moment-1.jpg`
- `moment-2.jpg`
- `moment-3.jpg`

Use your own couple photographs. The page keeps the designed floral placeholder visible until a matching image file exists. Images are cropped within a portrait frame; use high quality portrait or square originals for best results. To add more slides, edit the `moments` array in `src/components/PhotoGallery.jsx`.
